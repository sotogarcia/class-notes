# Movimiento

## Con el ratón

Clic                    Sitúa el cursor en el punto donde se hace clic

## Con el teclado

### Teclas de navegación

←                       Un carácter a la izquierda
→                       Un carácter a la derecha
↑                       Una línea hacia arriba
↓                       Una línea hacia abajo
Inicio                  Principio de la línea
Fin                     Final de la línea
Re Pág                  Una pantalla hacia arriba
Av Pág                  Una pantalla hacia abajo

### Con la tecla Ctrl

Ctrl + ←                Principio de la palabra actual o anterior
Ctrl + →                Principio de la palabra siguiente
Ctrl + ↑                Principio del párrafo actual; al repetir, principio del anterior
Ctrl + ↓                Principio del párrafo siguiente
Ctrl + Inicio           Principio del documento
Ctrl + Fin              Final del documento
Ctrl + Re Pág           Alterna entre el texto y el encabezado
Ctrl + Av Pág           Alterna entre el texto y el pie de página

### Con la tecla Alt

Alt + Re Pág            Principio de la página anterior
Alt + Av Pág            Principio de la página siguiente

# Selección

## Con el ratón

Arrastrar                Selecciona el texto recorrido
Doble clic               Una palabra
Triple clic              Una frase
Cuádruple clic           Un párrafo

## Con el teclado

### Seleccionar todo

CTRL + A                Selecciona todo

### Modos de seleccióN

F8                       Activa el modo de selección extendida
MAYÚS + F8               Activa el modo de selección de añadido
CTRL + MAYÚS + F8        Activa el modo de selección de bloque

### Teclas de navegación

Mayús + ←                Un carácter hacia la izquierda
Mayús + →                Un carácter hacia la derecha
Mayús + ↑                Una línea hacia arriba
Mayús + ↓                Una línea hacia abajo
Mayús + Inicio           Hasta el principio de la línea
Mayús + Fin              Hasta el final de la línea
Mayús + Re Pág           Una pantalla hacia arriba
Mayús + Av Pág           Una pantalla hacia abajo

### Con las teclas Ctrl y Mayús

Ctrl + Mayús + ←         Palabra por palabra hacia la izquierda
Ctrl + Mayús + →         Palabra por palabra hacia la derecha
Ctrl + Mayús + ↑         Hasta el principio del párrafo; al repetir, hasta el párrafo anterior
Ctrl + Mayús + ↓         Hasta el final del párrafo; al repetir, hasta el párrafo siguiente
Ctrl + Mayús + Inicio    Hasta el principio del documento
Ctrl + Mayús + Fin       Hasta el final del documento

### Con las teclas Alt y Mayús

Alt + Mayús + Re Pág     Hasta el principio de la página anterior
Alt + Mayús + Av Pág     Hasta el principio de la página siguiente

## Con el ratón y el teclado

MAYÚS + clic             Extiende la selección hasta el punto donde se hace clic
CTRL + arrastrar         Añade una selección no contigua
ALT + arrastrar          Selecciona un bloque rectangular
