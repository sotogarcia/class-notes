# Métodos abreviados de teclado de Microsoft Word

> Clasificación elaborada a partir de la salida de la macro `ListarComandos` de Word

## Criterios de revisión

- Se conservan las combinaciones asignadas en la instalación analizada, aunque puedan diferir de otros equipos, idiomas, plantillas, complementos o personalizaciones
- Se elimina el duplicado exacto `Alt + Mayús + T` para mostrar todos los títulos
- Se normaliza `Terminar` como `Fin` y se aclaran las referencias al `5 del teclado numérico`
- Cuando Word devuelve el nombre genérico `Estilo`, se mantiene una descripción prudente porque la macro no identifica qué estilo concreto está vinculado a cada combinación
- Una misma combinación puede aparecer en más de una categoría cuando Word la resuelve según el contexto
- Los comandos contextuales solo actúan cuando existe el elemento adecuado, como un campo, una tabla, un título, una ecuación o una selección
