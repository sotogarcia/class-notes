# Movimiento y selección en Microsoft Word

> Atajos para Microsoft Word para Windows con interfaz en español

# Movimiento

## Con el ratón

| Acción | Resultado |
|---|---|
| Clic | Sitúa el cursor en el punto donde se hace clic |

## Con el teclado

### Teclas de navegación

| Tecla | Resultado |
|---|---|
| ← | Un carácter a la izquierda |
| → | Un carácter a la derecha |
| ↑ | Una línea hacia arriba |
| ↓ | Una línea hacia abajo |
| Inicio | Principio de la línea |
| Fin | Final de la línea |
| Re Pág | Una pantalla hacia arriba |
| Av Pág | Una pantalla hacia abajo |

### Con la tecla Ctrl

| Combinación | Resultado |
|---|---|
| Ctrl + ← | Una palabra hacia la izquierda |
| Ctrl + → | Una palabra hacia la derecha |
| Ctrl + ↑ | Principio del párrafo actual; al repetir, principio del párrafo anterior |
| Ctrl + ↓ | Principio del párrafo siguiente |
| Ctrl + Inicio | Principio del documento |
| Ctrl + Fin | Final del documento |
| Ctrl + Re Pág | Principio de la página anterior |
| Ctrl + Av Pág | Principio de la página siguiente |

### Con las teclas Ctrl y Alt

| Combinación | Resultado |
|---|---|
| Ctrl + Alt + Re Pág | Parte superior de la pantalla |
| Ctrl + Alt + Av Pág | Parte inferior de la pantalla |

### Ubicaciones de edición

| Combinación | Resultado |
|---|---|
| Mayús + F5 | Vuelve a la ubicación de la modificación anterior; al abrir un documento, vuelve a la última modificación realizada antes de cerrarlo |
| Ctrl + Alt + Z | Recorre las ubicaciones de las cuatro modificaciones anteriores |

# Selección

## Con el ratón

| Acción | Resultado |
|---|---|
| Arrastrar | Selecciona el texto recorrido |
| Doble clic | Selecciona una palabra |
| Ctrl + clic | Selecciona una frase |
| Triple clic | Selecciona un párrafo |
| Clic en el margen izquierdo | Selecciona una línea |
| Doble clic en el margen izquierdo | Selecciona un párrafo |
| Triple clic en el margen izquierdo | Selecciona todo el documento |

## Con el teclado

### Seleccionar todo

| Combinación | Resultado |
|---|---|
| Ctrl + E | Selecciona todo el contenido del documento |

### Modo de selección extendida

| Tecla o combinación | Resultado |
|---|---|
| F8 | Activa el modo de selección extendida |
| F8 varias veces | Amplía sucesivamente la selección a la palabra, la frase, el párrafo, la sección y el documento |
| Mayús + F8 | Reduce la selección |
| Ctrl + Mayús + F8 y teclas de dirección | Selecciona un bloque vertical de texto |
| Esc | Desactiva el modo de selección extendida |

### Teclas de navegación

| Combinación | Resultado |
|---|---|
| Mayús + ← | Un carácter hacia la izquierda |
| Mayús + → | Un carácter hacia la derecha |
| Mayús + ↑ | Una línea hacia arriba |
| Mayús + ↓ | Una línea hacia abajo |
| Mayús + Inicio | Hasta el principio de la línea |
| Mayús + Fin | Hasta el final de la línea |
| Mayús + Re Pág | Hasta la parte superior de la pantalla |
| Mayús + Av Pág | Hasta la parte inferior de la pantalla |

### Con las teclas Ctrl y Mayús

| Combinación | Resultado |
|---|---|
| Ctrl + Mayús + ← | Una palabra hacia la izquierda |
| Ctrl + Mayús + → | Una palabra hacia la derecha |
| Ctrl + Mayús + ↑ | Hasta el principio del párrafo actual |
| Ctrl + Mayús + ↓ | Hasta el final del párrafo actual |
| Ctrl + Mayús + Inicio | Hasta el principio del documento |
| Ctrl + Mayús + Fin | Hasta el final del documento |

### Hasta la parte inferior de la ventana

| Combinación | Resultado |
|---|---|
| Ctrl + Alt + Mayús + Av Pág | Desde la posición actual hasta la parte inferior de la ventana |

## Con el ratón y el teclado

| Combinación | Resultado |
|---|---|
| Mayús + clic | Extiende la selección hasta el punto donde se hace clic |
| Ctrl + arrastrar | Añade una selección no contigua |
| Alt + arrastrar | Selecciona un bloque rectangular |
